# 영상 라이브러리 릴리스

[영상 라이브러리(my-video-manager)](https://github.com/vananaHope/my-video-manager)의 **설치 파일과 업데이트 파일**을 배포하는 공개 저장소입니다. 소스 코드는 이 저장소에 없습니다.

- 최신 버전: [Releases](https://github.com/vananaHope/my-video-manager-releases/releases/latest)에서 `MyVideoManager-Setup-<버전>.exe`를 받아 실행합니다.
- 앱 안 업데이트는 이 저장소의 최신 릴리스를 확인하고, Ed25519로 서명된 `update-manifest.json`의 크기·SHA-256과 맞는 파일만 설치합니다.
