# My Video Manager (영상 라이브러리)

Windows용 개인 영상 라이브러리입니다. PC 곳곳의 영상을 모아 썸네일로 보여 주고, 창 안에서 재생하며, **자막을 자동으로 만들고 번역·다듬기**까지 합니다.

이 저장소는 **설치 파일과 업데이트 파일을 배포**하는 곳입니다. 소스 코드는 여기에 없습니다.

**최신 버전 받기 → [Releases](https://github.com/vananaHope/my-video-manager-releases/releases/latest)**

## 주요 기능

| 기능 | 설명 |
|---|---|
| 라이브러리 | 감시 폴더를 하위 폴더까지 검사해 썸네일·제목·해상도를 보여 줍니다. 시리즈를 자동으로 묶고 태그를 붙입니다. 파일을 옮기거나 이름을 바꿔도 내용으로 같은 영상을 알아봅니다. |
| 재생 | mpv로 창 안에서 재생합니다(HEVC·AC3·DTS 등). 이어 보기, 배속, 키 배치 변경, 아래 조작 줄의 단추, 영상 클릭(재생/일시정지)·더블클릭(전체 화면)을 지원합니다. |
| 무작위 재생 | 라이브러리 결과·고른 태그·영상 전체에서 하나를 골라 바로 재생합니다. 🔀 **무작위 이어 재생**을 켜면 영상이 끝날 때마다 같은 범위에서 이어서 고릅니다. |
| 하이라이트 | 재생 중 지점·구간을 표시하고 메모와 태그를 남깁니다. **모아보기**로 복습합니다. |
| 자동 자막 | GPU 받아쓰기(faster-whisper)로 원어 자막을 만듭니다. 대기열과 자동 규칙(폴더·태그)을 둘 수 있습니다. |
| 번역 | Codex·Claude CLI 또는 OpenCode Go(API)로 한국어 자막을 만듭니다. 맥락 줄과 용어집으로 일관성을 높입니다. |
| 한국어 다듬기 | 한국어 영상은 띄어쓰기·문장부호·오인식을 고친 **다듬은 자막**을 따로 만듭니다. |
| 외부 자막 | 영상 옆의 SRT·VTT·SMI를 가져와 함께 검색합니다. |
| 검색 | 원어·번역·외부 자막의 대사로 장면을 찾아 그 위치부터 재생합니다. |
| 추천·통계 | 이어 보기·하이라이트 복습·새로 추가됨·다시 보기·잊고 있던 영상을 줄별로 추천하고, 시청 시간·일별 차트·라이브러리 구성(길이·형식·해상도)을 보여 줍니다. |
| 백업 | 라이브러리를 ZIP으로 백업하고 되돌립니다. 데이터 형식을 올리기 전에는 자동으로 백업합니다. |
| 트레이 | 창을 닫으면 트레이로 숨고, 한 번만 실행됩니다. **긴급 탈출** 키(기본 Ctrl+Shift+H)나 트레이 **창 숨기기**로 일시정지하고 바로 숨길 수 있습니다. |

## 필요한 환경

- **Windows 10/11 64비트**
- **자동 자막(받아쓰기)**: NVIDIA GPU와 최신 드라이버. 처음 쓸 때 CUDA 라이브러리와 Whisper 모델(약 4.3GB)을 내려받습니다. GPU가 없어도 라이브러리·재생·외부 자막·검색 등 나머지 기능은 쓸 수 있습니다.
- **번역**: 아래 셋 중 하나
  - [Codex CLI](https://github.com/openai/codex) 설치 후 로그인
  - [Claude Code CLI](https://docs.anthropic.com/claude-code) 설치 후 로그인
  - OpenCode Go API 키(설정 → 번역에서 등록, Windows에 암호화해 저장)
- 동영상 재생(libmpv)과 FFmpeg는 설치 파일에 들어 있어 따로 설치할 필요가 없습니다.

## 설치

1. [Releases](https://github.com/vananaHope/my-video-manager-releases/releases/latest)에서 `MyVideoManager-Setup-<버전>.exe`를 받아 실행합니다. 관리자 권한은 필요 없습니다.
2. 시작 메뉴에서 **My Video Manager**를 엽니다.
3. **폴더 관리(Ctrl+7) → 감시 폴더 추가**로 영상 폴더를 등록합니다. 검사가 끝나면 라이브러리(Ctrl+1)에 영상이 보입니다.

> 코드 서명을 하지 않아 처음 실행할 때 Windows SmartScreen 경고(“Windows의 PC 보호”)가 뜰 수 있습니다. **추가 정보 → 실행**을 누르면 됩니다. 걱정되면 아래 방법으로 파일을 먼저 확인하세요.

### 받은 파일 확인하기

각 릴리스에는 설치 파일의 SHA-256 값(`.sha256`)이 함께 올라와 있습니다. PowerShell에서 아래 값이 `.sha256` 파일 내용과 같은지 확인합니다.

```powershell
Get-FileHash .\MyVideoManager-Setup-<버전>.exe -Algorithm SHA256
```

## 업데이트

- **앱 안에서**: 설정 → 업데이트에서 **지금 확인**을 누르거나, 시작할 때 자동으로 확인합니다(끌 수 있음). 새 버전이 있으면 탭 아래에 알림이 보이고, **업데이트**를 누르면 받아서 설치합니다.
  - 가능하면 수 MB 크기의 **패치 설치 파일**을 받고, 패치를 쓸 수 없는 버전이면 전체 설치 파일을 받습니다.
  - 받은 파일은 Ed25519로 서명된 `update-manifest.json`의 크기·SHA-256과 일치할 때만 설치합니다. 다르면 지우고 다시 시도를 안내합니다.
  - **이 버전 건너뛰기**로 특정 버전 알림을 끌 수 있습니다.
- **직접 설치**: 새 버전의 `MyVideoManager-Setup-<버전>.exe`를 같은 위치에 덮어 설치해도 라이브러리·자막·설정은 그대로 남습니다.
- 직접 설치하기 전에는 트레이 아이콘 메뉴에서 **완전 종료**하세요. 창을 닫기만 하면 트레이에 남아 있습니다.

## 기본 조작

| 키 | 화면 이동 |
|---|---|
| Ctrl+1 ~ 8 | 라이브러리 · 추천 · 모아보기 · 검색 · 자막 대기열 · 통계 · 폴더 관리 · 설정 |
| F1 | 키 안내: 앱 전체 키와 지금 화면의 키 |
| Esc | 재생을 끝내고 직전 화면으로 |
| Ctrl+Shift+H | 긴급 탈출: 일시정지하고 창을 트레이로 숨김 |
| Ctrl+Shift+R | 영상 전체에서 무작위 재생 |

| 키 | 재생 화면 |
|---|---|
| Enter | 재생 / 일시정지 |
| ← / → | 5초 뒤로 / 앞으로 |
| ↑ / ↓ | 속도 +0.25 / −0.25 |
| Insert / Delete | 지점 하이라이트 / 구간 하이라이트 시작·끝 |
| PgUp / PgDn | 이전 / 다음 영상(시리즈에서는 이전 / 다음 화) |
| `/` · `.` | 자막 켜기·끄기 · 원어 ↔ 번역 자막 전환 |

모든 키는 **설정 → 키 배치**에서 바꿀 수 있고, 재생 화면 아래 조작 줄의 단추도 같은 명령을 실행합니다.

## 파일 위치

| 위치 | 내용 |
|---|---|
| `%LOCALAPPDATA%\Programs\MyVideoManager` | 설치 폴더. 제3자 라이선스는 `THIRD-PARTY-NOTICES.txt`와 `licenses\`에 있습니다. |
| `%USERPROFILE%\.my-video-manager` | 데이터 폴더: 라이브러리 DB, 썸네일, 받아쓰기 모델, 백업(`backups\`), 기록(`logs\`), 받은 업데이트(`updates\`) |

앱은 영상 파일을 지우거나 고치지 않습니다. 라이브러리에서 **제외**해도 실제 파일은 그대로입니다.

## 제거

1. 트레이 아이콘 메뉴에서 **완전 종료**합니다.
2. Windows **설정 → 앱 → 설치된 앱**에서 **My Video Manager**를 제거합니다.
3. 데이터 폴더(`%USERPROFILE%\.my-video-manager`)는 제거해도 남습니다. 라이브러리와 자막을 모두 지우려면 이 폴더를 직접 지우세요. 다시 설치할 계획이면 남겨 두면 그대로 이어서 쓸 수 있습니다.

## 문제가 생겼을 때

- **업데이트 설치 실패**: 앱을 다시 실행하면 결과와 설치 기록 위치(`updates\installer.log`)를 알려 줍니다. 패치를 적용할 수 없으면 **전체 설치 파일로 다시 시도**를 누르세요.
- **자동 자막이 시작되지 않음**: NVIDIA 드라이버를 최신으로 올리세요. 첫 자막 요청 때 화면 위에 **자막 기능 준비**(GPU 확인, 약 4.3GB 내려받기)가 나타나며, 이 준비가 끝나야 받아쓰기가 시작됩니다.
- **번역이 실패함**: 설정 → 번역에서 고른 방식(Codex·Claude CLI 로그인 상태, OpenCode Go 키)을 확인하세요.
- **그 밖의 오류**: 데이터 폴더의 `logs\app.log`에 기록이 남습니다.
